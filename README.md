# Placement Path — GitHub Pages edition

1. Create a repository on GitHub. GitHub Free requires a public repository for Pages.
2. Extract this ZIP and upload its files into the repository root. index.html must be at the root, not inside a folder.
3. Commit on main.
4. Open Settings > Pages. Choose Deploy from a branch, main, / (root), then Save.
5. Wait for the Pages deployment to finish in Actions, then use Visit site in Settings > Pages.

No installation or build is needed. Do not upload a personal progress backup.

Progress is saved only in this browser on this website address. Export your JSON backup from the original dashboard and import it on your GitHub Pages dashboard. Different browsers/devices/domains do not sync automatically.

The site includes study material, prompts and self-assessed interviews, not an AI service or voice evaluator. Copy tutor/feedback prompts into ChatGPT manually.
